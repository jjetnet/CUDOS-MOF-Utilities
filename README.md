# CUDOS-MOF-Utilities
CUDOS MOF Utitlities, software to calculate the modes of photonic crystal fibres, and scattering from cylinders, using the multipole (Rayleigh) method

The original page for downloading the software is down, this is a temporary access for the executable files. The source code will follow.
For usage, see the old wiki page [for installation](https://www.physics.sydney.edu.au/~borisk/CUDOS_MOF_Utilities.static/index.php/Installing_the_new_version.html)  and [notes for usage](http://www.physics.usyd.edu.au/~borisk/CUDOS_MOF_Utilities.static/index.php/Using_the_latest_version_of_the_software.html) noting links to the executables are broken, download here instead.
